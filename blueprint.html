✍️Script Studio — Full Spec
Model: Claude Sonnet 4
Styles: 12 (faceless, horror, motivational, educational, documentary, cartoon, comparison, avatar, shorts, kids, true crime, finance)
Languages: English, Hindi, Hinglish
Output schema: {hook, intro, body[], emotional_beats[], cta, outro, retention_tips[], engagement_score, word_count, estimated_duration}
Validation: Hook ≤35 words, CTA present, duration within 15% of target
Retry: Once on validation fail, then surface to user
Warning: Factual claims in educational content flagged for verification
⚙️Auto Editor — Full Spec
Stack: FFmpeg + fluent-ffmpeg + BullMQ + Redis + R2
Render steps: Asset validate → Ken Burns zoom → SRT → Audio mix → Concat → Captions → Grade → Watermark → H.264 encode → Upload
Voice: -16 LUFS normalized
Music: -24 LUFS, duck to -35 during voice
Color grade: Contrast +5%, saturation +3%
Targets: 60s → <90s render, 8min → <5min, 20min → <15min
Progress: WebSocket events every step
