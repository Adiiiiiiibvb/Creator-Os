Go Live — 4 Steps
No build tools required
🚀
Deploy in minutes
All files are self-contained HTML — they deploy as-is to any static host.
1
Download all 16 files into one folder
Keep every file in the same folder — they link to each other by filename (e.g. href="dashboard.html"). Do not rename files.
2
Pick a host
Any static host works — no server, database, or build step needed for the prototype.
🟩
Netlify Drop
Drag folder to netlify.com/drop
RECOMMENDED
▲
Vercel
npx vercel in folder
⬛
GitHub Pages
Push + enable Pages
🟠
Cloudflare Pages
Connect repo, auto-deploy
🖥️
Your Web Host
Upload via FTP/cPanel
🟡
Amazon S3
Static website hosting
3
Choose your homepage
Pick which file your visitors land on first:
# Public website → set vision3-platform.html as homepage # (rename to index.html, or configure host to serve it as root) # Internal review → keep this file (START-HERE.html) as entry point # Direct app access → set dashboard.html as homepage
4
Enable Live AI (optional)
ai-studio.html calls the Anthropic Claude API directly. Without a key it runs in demo mode (works great for presentations).
// In ai-studio.html, the fetch() headers need: headers: { 'Content-Type': 'application/json', 'x-api-key': 'sk-ant-YOUR-KEY', 'anthropic-version': '2023-06-01' }
⚠️
Never expose API keys in client-side HTML for production. Use a backend proxy. Demo mode is safe to deploy publicly as-is.
